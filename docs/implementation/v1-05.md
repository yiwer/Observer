## 实际 CLI 与模型协议

固定参数为 `--bare -p --restricted --tools '' --permission-mode dontAsk --strict-mcp-config --mcp-config '{"mcpServers":{}}' --disable-slash-commands --no-session-persistence --model claude-sonnet-4-6 --max-turns 4 --output-format stream-json --verbose --json-schema <draft-07 schema>`。Prompt 通过 stdin 投送；没有 `--add-dir`、fallback、resume、hooks、shell、检索工具或外部 MCP。`--permission-prompts none` 要求更高版本，本票没有使用；`--help` 短路不被视作参数兼容性证据。这组参数通过 Linux 真 CLI 正常链路运行。

模型标识固定为 `claude-sonnet-4-6`，不接受 `sonnet` 等移动 alias。2026-09-05 [官方生命周期表](https://platform.claude.com/docs/en/about-claude/model-deprecations) 将它列为 Active；这不是此 Owner 的账户/地区可用性证明。实际模型服务和模型质量未测。

**实测差异**：`--tools ''` 不移除 CLI 自带的 `StructuredOutput` 数据工具。初次仅返回普通文本导致没有 `structured_output`，即使最终 subtype=success 也不能出版。成功样本需要 Messages SSE 中 `tool_use(name=StructuredOutput, input=<候选>)`，CLI 输出 init→assistant 数据工具→user 成功确认→result，最后 supervisor 等待真实子进程 exit 和 EOF。Zod 为 Claude 显式输出 draft-07。样本见 [success.jsonl](../../tests/fixtures/claude/success.jsonl) 和 [来源/脱敏说明](../../tests/fixtures/claude/README.md)。

成功要求固定版本、init 工具/MCP/skills/目录/模型策略一致、同 session、数据工具已完成、唯一 result、subtype=success、is_error=false、terminal_reason=completed、stop_reason 为 tool_use/end_turn、无 permission_denials/errors/api_error_status、结构/任务/Bundle/配置/栏目一致、外层子进程与 Docker exit 都为 0，并且任务树回收已证实。部分正文或已完成的数据工具不是发布授权。拒绝、max_tokens、取消、已知/未知错误终态、重复/坏事件和缺失结构均失败。文档允许的尾随 `system/prompt_suggestion` 继续消费且不归档；其他未知终后事件失败。

参考：[CLI 参数](https://code.claude.com/docs/en/cli-reference)、[非交互模式](https://code.claude.com/docs/en/headless)、[结构输出](https://code.claude.com/docs/en/agent-sdk/structured-outputs)、[agent loop/result](https://code.claude.com/docs/en/agent-sdk/agent-loop#handle-the-result)、[官方类型固定 commit b1b838b](https://raw.githubusercontent.com/anthropics/claude-agent-sdk-python/b1b838b1c5730a7a0b270915a79b15861a8ca716/src/claude_agent_sdk/types.py)。字段验收以固定 Linux 二进制实测样本和代码规则为准，不把 main 文档新特性回填为旧版本实测。

## 权限、生命周期与用量

检索面限定为已许可 Evidence Bundle 的只读 stdin 数据；正常候选路径完整运行，不把功能降为 parser-only。真实 CLI 没有 Bash/Read/Edit/WebFetch/Agent/MCP 等工具，唯一 StructuredOutput 数据入口的 Schema 与名称由宿主固定。模型响应中未知工具、Bash、文件、MCP、服务端工具，以及不完整/重复 SSE，在交给 CLI 前被拒绝。宿主请求只保留经验证的 messages/system 和固定模型、输出/思考/工具参数；messages仅允许文本、思考及已验证StructuredOutput历史，tool_result内容递归只允许文本，system仅文本。不允许image/document/file等隐含远程获取或私有文件引用，不转发 `mcp_servers`、container/skills、metadata、beta 或认证头。请求解析失败在进程回调内转为policy-violation、清理任务树，外部transport调用次数为0。

容器 `network=none`，仅挂载可信 worker（或显式测试协议程序），非 root 65534、只读根、cap-drop ALL、no-new-privileges、32 PID、1 CPU；Claude 内存上限 512 MiB。私有 `/run/observer` tmpfs 为16 MiB、noexec/nosuid，TMPDIR/配置/Home 都在其中。实测未设置 TMPDIR 时 CLI 尝试 `/tmp/claude-65534` 并因 EROFS 失败，当前配置已修正。noexec 不证明解释器不能执行脚本；候选代码不可执行主要依靠无执行工具、模型输出前置拒绝和不挂载候选仓库。OS 探针另验证直接可执行拒绝、宿主秘密路径不可读、业务配置/worker不可写、不能提权、外网/宿主 gateway/邮件端口不可达、broker 的方法/路径/Host/模型拒绝。

可信 supervisor 的环回 HTTP 只接受 `/v1/messages?beta=true`（这是实际 CLI 请求路径），将请求包成独立控制帧交宿主；候选 stdout 始终嵌套为 event，不能伪造控制帧。`createAnthropicModelTransport(apiKey)` 只向固定 `https://api.anthropic.com/v1/messages` POST，固定 `anthropic-version: 2023-06-01`，不跟重定向。外部 key 保留在宿主闭包，容器仅有不具账户权限的 `observer-inert-local-broker` 占位值。API 传输代码存在但此次未调用真实端点。没有读取 OAuth、API key、系统 keychain 或保存认证。[API 契约](https://platform.claude.com/docs/en/api/messages/create)、[认证说明](https://code.claude.com/docs/en/authentication)、[安全部署](https://code.claude.com/docs/en/agent-sdk/secure-deployment)。

默认总时限60秒（可配置100毫秒至300秒）、模型发送最多4次（1–8）、CLI最多4 turns；没有整任务自动重试、并发扇出或金额上限。输入最多1 MiB、模型响应2 MiB、stdout/stderr总计默认2 MiB（可配置1 KiB–8 MiB）。这些是当前操作性限制，不是生产容量验收。取消同时 abort 宿主 HTTP 和 Docker client，最终按 exact container ID + 随机name/label + Created + image 核对后强制移除整个任务树，再读回确认；失败回收不能转成功，绝无全局 prune 或裸 PID 扫杀。

日志只保存结构化运行状态、版本、时长、exit、固定失败类别和安全数字用量。stderr只计字节、不存正文；Docker logging driver为none，实际docker logs不可读，原始source/model控制帧不会进入daemon日志。原始事件不进入报告；协议样本只有明确许可的虚构内容。没有新增持久原文或秘密备份。

Claude 的 `modelUsage` 是整树总量，`usage` 是主 loop；优先整树，不相加。每个实际宿主发送保存有界数字receipt（1–8）作为来源明确的后备；重复/缺失/坏usage保留null，崩溃合成error_during_execution的归零总量不替代已观察receipt。API响应在工具拒绝前提取usage，因此安全拒绝也保留已取得的量；未知费用不设0。CLI cost是客户端估计，协议替身cost不是实际账单。

Bundle v2每次发送前以Runner私有快照重新校验TTL，进程请求/模型响应不能延长授权。Observer先执行字段许可投影；Gate继续检查来源与分发，Archive Bundle v3不存content并保留collected policy身份。首发过期、二次发送过期及合法字段裁剪/正文归档都有T1测试。

# V1-18：Canonical Markdown 到中文 PDF

报告发布事务通过 SQLite trigger 创建独立 `pdf_renditions` 任务；启动时也为旧报告补建任务。`main.ts` 每秒独立驱动 `observer.processPdfRenditions()`，不要求当天研究调度开启。转换只读取 `observer.readReport()` 返回的已持久 Canonical 全文与版本信息，不接收 Report Record，不调用 Provider，也不从 Completion 的本次 `record.stories` 重建整刊。已发布 MD 及邮件 outbox 不被 PDF 失败修改或阻塞。

默认 `pdf: { enabled: true }`，可在运行配置设为 false 暂停新转换；已有 PDF 仍可下载。V1 只生成精确版本的**完整日报**，旧版/被取代版保留自身 PDF，最新版本不会借用旧版 PDF。撤回版本拒绝正文下载。`edition` 不为 null 的 PDF 请求返回400 `pdf-full-report-only`，不会将整刊冒充栏目文件。

## 私有读取与状态

| API | 行为 |
|---|---|
| `GET /v1/reports/YYYY-MM-DD-vN/pdf` | Owner/设备 Bearer 获取已存 PDF，`application/pdf`、attachment、no-store |
| `POST /v1/reports/YYYY-MM-DD-vN/download-link?format=pdf` | 只为已就绪整刊签发原有5分钟对象授权 |
| `GET /v1/downloads/YYYY-MM-DD-vN/pdf?token=…` | 精确版本/格式/身份签名下载；不在请求中转换 |
| `GET /v1/archive/YYYY-MM-DD` | 每版 `renditions.pdf` 的可用性、scope、状态、尝试数、错误、源正文校验字段、引擎与大小/页数 |
| `GET /v1/sync` | 新 `rendition-state` 事件；和历史列表一样遵守固定快照高水位 |

未就绪返回404 `rendition-not-available`，可以继续读取同版 MD。设备撤销、签名过期、报告撤回和当前来源分发许可检查全部复用 #17 的读取链路；转换前、保存前、每次下载都检查来源可读性。转换期间 Worker 不持有凭据，日志只返回固定错误码。索引的 `available` 表示产物存在且未撤回；最终读取仍可能因当前 Source Policy 被拒绝。

状态为 `pending → processing → ready`，失败回 pending，最多实际尝试3次，间隔60秒，最终 failed。每次 Worker 最长60秒、512MiB V8 old-generation；崩溃后的120秒租约到期再恢复，已开始的尝试计数不回退。单次完整输出以 BLOB 和 ready 状态同事务保存，事件不携带 PDF 字节。停止进程不会将半成品标为成功。没有远程重试/编辑接口。内存上限不是整个进程的 RSS 限额；V1 未做容量调优。

## 转换与运行依赖

采用锁文件固定的 PDFKit 0.17.2、markdown-it 14.1.0、fontkit 2.0.4（均 MIT），与现有 Node 24.18+ 的24.x 运行时共用。PDFKit 的[文字排版](https://pdfkit.org/docs/text.html)支持自动换行/跨页、链接及嵌入字体；实现不设置正文高度或省略号。使用[CommonMark 预设](https://github.com/markdown-it/markdown-it/tree/14.1.0)，禁用 HTML 执行、自动改字和 linkify。标题、段落、有序/无序列表、引用、代码块和 Markdown 链接转为文本排版；原始 HTML 作为文字显示，Canonical 的空锚点仅用于导航。GFM 表格/脚注扩展未启用，其源文字按 CommonMark 显示。

所有图片、HTML 图片、CSS、嵌入资源均不加载；Markdown 图片显示替代文字与原地址，HTML 保留文字。这是 V1 更严格的资源策略，不新增任何 Source Policy 授权或受控网络出口。链接仅 http/https 可点击，且不接受 URL 用户名/密码；其余地址只显示文字，栏目锚点转为 PDF 内部跳转。转换器没有浏览器、模板执行、shell、HTTP 请求或从 Markdown 读取文件的代码路径。Worker 不是操作系统沙箱；防护来自只处理文本与固定字体的窄转换路径。

A4 单栏、中文正文、标题层级、分页和逐页刊次/页码。全文不静默截断；超过8MiB原始 MD、500页或32MiB PDF时明确失败，不保存部分输出。随库提供 [Noto Sans SC Sans2.004](../../assets/fonts/README.md)，按该版本 [OFL 1.1](https://github.com/notofonts/noto-cjk/blob/Sans2.004/LICENSE)分发；PDF 子集嵌入字形，无需客户端字体。缺字逐字显示 `[U+码位]` 并提示，精确原 MD 作为附件内嵌。版本 ID、修订/前版与现有 `canonicalMarkdownSha256` 写入产物信息；未引入开发验收 hash 检查。

Linux 重现：在仓库根目录执行 `npm ci`、`npm run build`，按 #15 配置启动。发布目录应一起保留 `dist/`、`node_modules/` 和 `assets/fonts/`（含 OFL）；没有 Python、浏览器或宿主字体依赖。仅视觉查看样张需要 Poppler，可用 `pdftoppm -f 1 -singlefile -scale-to 1400 -png report.pdf page-1`。没有执行 Docker、部署或 Linux 实机验收。

## 外部判断与确定性约束

每个 Edition 的每条 Claim 都须有完整且结构有效的 domain 判断。规则按 `domains` 和风险类别执行，与 Candidate 所选栏目无关。自由文本、未知枚举、缺失必填字段仅使该条注解不可用；相同合法回执中的其他合格 Claim 可继续。坏回执整体身份/摘要关系仍沿既有规则拒绝。

注解包含领域、routine/high/unknown 风险与类别、event-fact/attributed-statement/interpretation/unknown 断言性质、财经内容边界、逐 Evidence 材料性质、动态数字和逐 Evidence 研究状态。明确的 routine 与 none 是外部肯定判断；缺失不自动填成低风险或没有数字。`research` 在 AI/科技领域必须覆盖所引每份 Evidence，在其他领域可为空。

风险类别固定为 armed-conflict、casualty-disaster、election-count、public-health-emergency、finance-sensitive。high 必须有类别，routine 必须无类别；领域/类别重复及 unknown 不授权展示。Claim 的 fact 不能借 attributed-statement 或 interpretation 标签进入事实标题；只有 analysis 可用 interpretation。statement、analysis、quotation 中实际嵌入的高风险事实仍按 event-fact 执行交叉核验；纯解释/条件情景可保留分析标签。

| 条件 | 出版结果 |
|---|---|
| 高风险事实 | 至少两份可靠、非 publisher-statement 支持，且 Source 和已知 Upstream Origin 均不同；同源、同上游转载、未知上游不足时待确认。 |
| 高风险财经，包括跨领域财经 | 上述两源条件之外，至少一份适当 primary/direct-observation；只有两个二手源不足。 |
| 财经边界 | 所有 Claim kind 均禁止 trade-instruction、target-price、return-promise 和 unknown；实际财经领域必须为 informational。没有禁词表或从栏目推断安全性的逻辑。 |
| 不安全/无关材料 | unsafe wording/receipt、irrelevant Evidence、未核验社交视频、血腥图片或未知材料性质先隔离，不得因证据不足先变成可读待确认。 |
| 冲突/不足 | 安全原创说法可显示为“待确认说法（非已证事实）”，附支持/相反来源及固定中文原因；不能成为事实标题。引语未确认时不保留原句。 |

Source Policy 和最终许可/TTL 检查仍先于可展示结果。待审源、禁止模型材料不会进入 Verifier；分发/永久归档/引用禁止或最终过期的陈述不留下 domain projection。真实来源提案仅为 [Owner 待审记录](../research/domain-evidence-source-proposals-2026-09-05.md)，没有启用 FRED、行情源或任何新来源。

语义风险、事实支持、单方数字归因、独立验证和资料成熟度均由外部 SemanticVerifier 判断。JSON Schema、哈希、来源计数及本票替身测试只验证规则与关联，不能证明这些模型判断真实正确，也没有新增 Runner 之前对任意文本作可信分类的平台。真实中文表达、误报率和事实质量仍须 PRD T3 的后验评估。

## 动态数字与研究标签

`numbers.status` 必须明确 none/dynamic/unknown。dynamic 的每组统计值由外部判断给出 `statisticsAtUtc`、本 Claim 的 `evidenceIds` 和可空 `publisherSourceId`；语义是这些获准模型文本支持此统计时点及归因，而非材料发布时间。确定性门检查引用属于本 Claim、有可见 title/content、关系非无关且可靠、时点不晚于 cutoff 或取得时刻。不会从 publishedAt、事件发生时间或别条 Claim 自动代填。

统计数字本身若没有两份不同 Source/已知 Upstream 的可靠依据，就必须有与本组证据实际 Source 匹配的单方归因。相反来源可用于带时间的冲突区间；不会因矛盾消失而任选数字。未知时点、外来引用、无单方归因或伪 publisher ID 均隔离原数字。已经出版及安全待确认的原句都就近呈现“统计时间 / 依据 / 单方归因”。伤亡区间、计票比例、财经结算数字和未知最终总数有固定材料回放。

AI/科技每份所引 Evidence 分别显示预印本、官方发布、独立验证、同行评审的 yes/no/unknown，可组合，且保持未知。研究标签不能借用其他 Claim/Evidence，必须可关联本次获准模型文本。官方公司能力声明可作为带归因的发布行为；要把能力本身作为事实，须有可靠非单方支持的独立验证，且其 Source 与已知 Upstream 不同于公司声明来源/上游。只有独立标签、同公司自测、同上游转载或未知上游均不足。

当“独立验证=yes”与公司来源/上游关系矛盾时，最终 Observer projection 将该标签收紧为 unknown，正文也显示未知，不把原矛盾注解当独立验证结果。原始注解 SHA 保留作为输入关联标记，不能拿最终投影重新计算并冒充原始模型回执。

## 材料与永久档案

现有 Bundle 仅接收文本与许可元数据；二进制 content、额外 media/video 输入字段拒绝。没有媒体下载、URL 解引用、图像渲染或图片事实核验能力。逐 Evidence 的 text / verified-media-description 只允许外部已判定可用的文字材料；后一类是核验过的文字描述，不是新增媒体入口。unverified-social-video / graphic-imagery / unknown 不能作为出版材料。若在 Verifier 阶段才识别到不安全文字，会隔离最终报道材料，但不声称阻止过此前已发生的文本研究发送。

所有请求版本均删除原始 `domain` 和外部伪造 projection；外部直接提交 projection 使回执无效。仅最终发布门允许的 published/unconfirmed Claim 保留受限 `observer-final-domain-projection-v1`：固定枚举、已校验 Evidence/Source 引用、UTC 时点和 annotation SHA。它明确是 Observer 的最终投影；Verifier 的原 inputSha、版本、provenance 和实际批次保持原身份。隔离原文、原始来源 content 和无效自由字段不进入永久 Report。最终中文正文仍只从已归档 Record 生成。

## 公开使用与文件生命周期

沿已确认的 PRD T1：本地 Owner 文件配置 → `createObserver().produce()` → 鉴权 `readReport()`，真实 SQLite 可重启。增加的 `importInterestProfile(filePath)`、`exportInterestProfile(filePath)` 是同一公开 Interface 的本地配置前置操作；没有 HTTP 管理路由或 test-only 入口。

```ts
// app 是按既有契约组成的 Observer；Runner/Verifier 与来源权限仍须分别满足。
app.importInterestProfile("./config/interest.example.v1.json");
const version = await app.produce({ ...sixEditionTask, schemaVersion: 4 });
const report = app.readReport(version.id, ownerToken);
app.exportInterestProfile("./data/interest-export-v1.json");
```

[初始配置](../../config/interest.example.v1.json) 明确采用空 topics/entities/exclusions，CN/US/EU 各 priority 1；没有推断 Owner 私人兴趣。有限语言目标为 zh、en、fr、de：中文成稿的常规发现目标、英语跨区域资料，以及两个欧盟语言观察目标。它们不代表全部欧盟语言、不启用新来源，也不证明采集/翻译能力。未覆盖语言必须作为盲区看待。

Owner 编辑的是**输入文件**，随后显式 import。应用在 `<databasePath>.interest.json` 保存验证后的 active 快照，包含 profile 和 SHA-256；该文件不是 Owner 编辑入口。生产 request 4 在第一个 await 之前读取并拷贝 active 快照，之后的 import 只影响下次生产。刊次完整保存快照，不因 active 改动或损坏而改变已发布内容。

- Profile schema 1：正整数 `version`；topics/entities/regions 的 `{key, priority: 0..100}`；三种 exclusions；有限 `coverageLanguages`。未知字段、空 key、超限、非法优先级、规范化后重复 key 和重复语言拒绝。输入最大 256 KiB，须为普通文件。
- topics/entities 以 NFKC、去首尾空白、合并空白、小写后**完整键匹配**；没有关键词搜索或子串推断。地区键是双大写字母标识，CN/US/EU 有固定常规含义，其余明确地区键属于 other 聚合桶；语言标识按受限语法验证，比较时小写，不假定语言族或地域映射。
- 更高 version 可以导入；同 version 同规范化内容幂等；同版改内容或回滚失败。更改列表顺序也属于内容变更，须升版。导出是可重新导入的 Profile 文件，不是应用 active 包装。
- 验证/版本检查完成后，先写同目录唯一临时文件，再 rename 切换 active。失败不覆盖上一有效版；不做目录清理。同步操作序列化本进程调用，不声称跨进程事务或跨 SQLite/文件事务；部署须由单个配置写入进程负责。
- export 使用 `wx`，拒绝覆盖现有文件，并显式拒绝 archive/active 路径。没有 active 时 request 4 报错；active 损坏时 import/export/新生产失败，不制造默认或声称恢复。先前 Report 仍按自身快照可读。磁盘恢复与备份属于后票。
- 本地文件配置操作和 produce 一样由受信调用者持有；不构成新增远程权限。没有阅读时长、点击学习、画像、自动偏好写回。

## 判定表与元数据权威

| 次序/场景 | 判定与可观察结果 |
|---|---|
| Source Policy、Publication Gate | 既有采集/存储/模型/分发授权与最终 TTL 重查优先；任何偏好和 baseline 都不能越过。 |
| Event Cluster / 时间 | 先执行 V1-07 的归类、历史新进展、首次披露/补报、未知时间与去重。截稿后普通证据拒绝；未知披露不靠 baseline 补时间。 |
| 元数据来源 | 现 SemanticVerifier 可返回逐 Claim 的 selection annotation。Candidate 标题、自报 cluster ID、关键字、域名、Owner profile 都不授予事件元数据或重大性。 |
| Global Baseline | 仅新闻 Event Cluster 可取得。相同最终已发布 fact/statement 的 event projection 必须为 material；selection impact 为 global/major-regional，且有该成员实际保留的已发布 analysis Claim 支撑。 |
| statement | selection 的 impactBasis 必须明确为 statement-act；仅评价已证“发表声明”的行为。observed-event 标签不能把承诺结果变成已发生事实。既有声明归因继续显示。 |
| 冲突/缺失标注 | 事件为 routine、impact analysis 缺失/隔离、外来 evidence ID、输入 digest 错配或最终 Gate 失效，均不授予 baseline。无法取得获准模型文本/标题时不接受 selection projection。 |
| 排除 | topic/entity/region 完整键命中则排除普通候选；有以上资格的 baseline 保留入选资格。baseline 不保证必须发布，也不补足配额。未知标注不能假称命中排除或兴趣，保守保留新闻资格并披露未知。 |
| 地域范围 | CN/US/EU 常规资格；其它已明确地区需 baseline 或显式 topic/entity/region 配置命中。priority 0 的显式键仍表示纳入意图，但不加分。没有任何已知地域的候选可保守保留，不能被统计成全球覆盖。 |
| cluster 多成员 | 主 Edition/主故事仍由 V1-07 决定。排序只用主故事实际承载的当前/补报事实及实际 supportingClaims；单纯重复成员/Impact Note 不给主条借题材、地区或 baseline 权威。每种配置键只加一次分。 |
| 排序/容量 | 去重之后、最终 7/3 截断之前：baseline 优先 → topics/entities/regions 命中 priority 总和降序 → story ID 固定字典序。第八个及之后的合格候选仍有机会。单主故事和不占位 Impact Note 保持。 |
| GitHub | 仅应用显式兴趣加权/排除，不用新闻地区范围排除仓库，不授予新闻 baseline；Heat、快照、新颖性和重新入榜规则仍由后票实现。 |

selection 是外部语义判断，不是确定性事实证明。原始 topic/entity 自由标签不进入永久 Report；仅在最终 Gate 后产生 `observer-final-selection-projection-v1`，保留 annotation hash、规范化标签 hash、受限 region/language/impact 枚举与限定在原 Claim 的 ID 引用。impactBasis 保持声明/发生事件的语义区分。协议自己返回 projection 会使该核验回执无效。request 1/2/3 上收到的新 annotation 同样剥离，不借旧版入档。

`interestSelections` 记录每个去重后候选的 score、baseline 与 eligible/excluded/outside-region-scope。eligible 表示仍有资格，容量未选中并非已经刊登；最终实际选择看 `editions.storyIds` 和 `stories`。Report 读取会核对快照 hash、已选故事的重新计算排序/资格以及覆盖投影，不重新读取当前配置或源文。

## 覆盖指标

`coverage.scope = model-input-and-final-gate-annotations`。`inputEvidenceCount` 明确计本期真正交给 **SemanticVerifier** 的去重 Evidence ID；不等于全网采集量，也不包括只有 Runner 看过而未进入核验的材料。

regions 固定 CN/US/EU/other；它描述已核验事件涉及的地域，不能当作出版者所在国。languages 包括配置目标和实际出现的语言标注；它描述核验中实际可见、许可允许文本/标题的语言，不声称全文语言探测或翻译能力。

每项同时保留：

- `evidenceIds`：在最终 Gate 后仍可使用、带有效语义标注的证据。研究阶段看到了美国事件，但该事件因偏好未选时，这份材料仍可计入 US evidence。
- `selectedStoryIds`：只通过实际选中 Claim 或 supportingClaim 的限定标注归属。共享一个文档不会把被排除美国事件的地域借给中国事件；Impact Note 单独说明关联，不冒充主故事的地域。
- `unknownRegionEvidenceIds` / `unknownLanguageEvidenceIds`：真正进入核验而无可用标注的证据；不会由 `.cn`、英语域名或空白配置填出地域/语言。

同文档可能包含多个地区/语言，桶非互斥，不能把桶相加当总证据数。已观察桶为零、未知信息、原有 source gap 均在 Today Overview 或对应栏可见。目标不全或没有新闻都不能从零结果推断。真正多语言来源召回率仍需后续真实影子评测。

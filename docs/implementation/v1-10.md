范围：[票 #10](../planning/v1/tickets/10-social-discourse-edition.md)，PRD US23–25 / AC05–06 / D5 / D6 / T1。实施起点 `f36aae2122d081e638bfd520f93ded88fc95ef3b`，分支 `ticket/v1-10`。本文记录作者实现契约和开发证据；Root 的冻结双轴审查、独立旧字节回放和 master 验收另记。真实平台、真实模型与生产启用均未验收。

## 公共路径与版本

沿已确认 T1：来源配置与时钟 → `createMastodonAdapter().capture(...)` → `createObserver().produce(request6)` → Runner / SemanticVerifier → Canonical Markdown / Report Record → 鉴权 `readReport` 与真实 SQLite 重启。HTTP 响应替身只替换外部 I/O，同一个 Mastodon Adapter 负责真实协议。没有私有函数、内部模块 mock 或 SQL 侧读作为业务验收入口。

| 契约 | 本票行为 |
|---|---|
| Request 6 | 六栏输入、有效 Interest Profile、可选 `discourseSamples`；配置在 Observer options 的 `discourse.configuration`，不由 Runner 决定。 |
| Record 7 / Version 6 | `observer-canonical-v5`；继续 `observer-domain-evidence-v1`；单独 `discourse.groups/observations`，不伪造普通新闻 Claim 或 Event Cluster。 |
| Candidate 2 / EditionResearch 2 / Verification 1 | 保持外壳、批次数和容量；Assessment 可带受限 `discourse` 语义判断。外部注解不能授予来源权利。 |
| Request 1–5 / Record 1–6 / Version 1–5 | 保留旧入口和 renderer，不回写旧记录，不借新规则声称旧记录已完成话语核验。 |
| SourcePolicy 1 | 新增可选 `social` 约束；缺省不插入字段，旧配置序列化与 digest 不变。社交字段缺失或用途未知不授权。 |
| SQLite | `user_version=1`；不改 reports 表及不可覆盖/删除触发器。 |

正常 HTTP 服务仍受既有 test-fixture 生产脊柱开关约束；本票不启用真实自动出版。默认未提供 discourse 配置时，Request 6 显示无合规社交来源 Gap。Request 5 仍使用原正文契约。后续 PDF / 邮件必须从同一个 Canonical 版本派生，其输入投影、渲染、投递尚未实现或实测。

## 来源权利与时点

依据 [ADR-0005](../adr/0005-separate-expiring-source-material-from-permanent-reports.md) 和[官方协议/条款研究](../research/mastodon-social-sample-adapter-2026-09-05.md)，技术上可 GET、软件开源、作者公开发帖、平台引用批准或 robots 允许均不是 Observer 用途授权。没有真实 Mastodon 实例获批；X、Reddit 等也未启用，没有购买数据或申请账户权限。

`SourcePolicy` 是 Owner 的受控输入，`feedUrl` 的精确 HTTPS origin 是实例白名单；查询 tag 必须位于 `social.allowedTags`。启用须同时满足：

- review 已批准且不晚于当前阶段；collection 开启且允许处理响应正文；storage 有正 TTL 且允许记录键；model 开启。
- collection / storage / model 均准许 url、title、content、contentSha256；匿名观点并非不受许可约束的旁路。
- distribution 开启且准许 url/title、原创衍生文字和永久归档；citation 开启；`irrevocableExportAllowed=true`。
- `allowApiResponseProcessing`、`allowStatusKeys`、`allowAnonymousText` 全 true；分别覆盖临时接收完整 API 表示、短期状态键/摘要、匿名观点处理。
- deletion.mode 为 owner-request，social.deletionScope 必须明确 raw-only。unknown 或 derived-and-exports 不能与永久不可变档案协调，直接关闭；不新增万能删除/可变报告系统。

| 时点 / Authority | 收紧行为 |
|---|---|
| capture 开始 | 严格解析 Owner policy、配置、组身份、日期与时间；缺用途在第一次 HTTP 前返回无许可 Gap。 |
| capture 返回 | 实际最后响应时刻、cutoff、配置/规则/政策摘要绑定完整快照摘要与随机 receipt；不得以 created_at 代替收到时间。 |
| produce 开始（任何 await 前） | 固定 clock、查询配置和 Interest Profile；后续导入 Profile 仅影响下次。严格解析快照，核对组/来源/政策版本/全部摘要/业务日/时间/计数/去重关系。 |
| Request6 模型投影 | 采样等待完成后读取该阶段的当前政策快照，同一份 Authority 同时判断来源的 social-discourse 分类与模型用途 / policy digest。非本次合法 capture 聚合路径的社交 Evidence 从普通 Bundle / Edition assignment 移除，不能因启动配置缺失、过时或等待期间新登记而绕过匿名投影；普通合法源保留。 |
| Runner 前、Runner 后、每批 Verifier 前后、最终成稿前 | 当前政策、TTL、同实例逐状态复查；变化只把组放入 sticky 隔离集合，不换正文、不换来源、不降低阈值。已隔离组不再发 HTTP。 |
| 每组 HTTP 前 / 整轮最后一个 await 后 | 下一组开始前重新读取当前政策；全部异步复查完成后，同步扫描所有组的当前政策与 TTL，不再发 HTTP。后一组等待期间撤销前一组也不能漏过。 |
| 最后异步复查之后 | 取唯一最终出版时刻，对所有仍可展示的 published / unconfirmed Claim 再执行完整来源政策与 TTL 检查；Gate.checkedAtUtc 与 Version.publishedAtUtc 相同，之后无异步等待。失效 Claim 的正文、待确认描述和自由语义回执不永久保留。 |
| public revalidate | 自己校验 receipt 完整摘要、原 sourceId / policy digest / origin / tag、完整当前用途和入口 TTL；最后 HTTP 返回后按取消、实际 deadline、TTL 顺序检查，失效 receipt 删除且不能因时钟回拨复活，不依赖 Observer 调用者帮它守门。 |
| 永久投影 | 删除原始内容、原始社会注解与最终失效组的全部语义回执；保留已允许的受限审计身份、摘要、状态、统计和 Gap。普通合格新闻不因一个社会组失败而整期报错。 |

`sourcePolicyReader?: () => unknown` 是可选受控配置读取 seam，各上述检查点重新读取并解析；默认 `sourcePolicies` 只在创建 Observer 时冻结，配置文件变化必须显式重新加载/重建实例，不声称自动监听磁盘。一次 adapter revalidate 使用调用时传入的政策快照，并非每个 socket 都另读磁盘；Observer 在每组 HTTP 前、该组 await 返回后以及整轮末尾分别读取当前政策/TTL。仅 Request6 social-discourse 的 Candidate2、每条 analysis 只引用该配置组唯一 aggregate Evidence，且组已 sticky 失效时，可在原 assignment 检查前隔离该候选；未知组、未知 Evidence、混用 Evidence 或错误 Edition 仍走原有非法输出检查，不能借已知组名绕过关联约束。

## Mastodon 最小协议与资源边界

只实现单 tag 的 `GET /api/v1/timelines/tag/{tag}?local=true&limit=20`，以及同实例 `GET /api/v1/statuses/{opaqueId}`。不读搜索、趋势、账户、完整线程、媒体、编辑历史或其他实例；不加 token，不自动申请权限。

协议依据固定到官方 v4.7.1 源码及本轮现行文档；尚不承诺某个真实实例的版本、分叉、条款或访问配置。ID 作为字符串，不转 Number / 不用其排序推断时间；为安全构造单路径段，拒绝 dot-segment、斜线、百分号和 URL 控制字符，而不是把它当整数。没有额外解引用 `uri/url`。

`created_at` 和非 null 的 `edited_at` 必须是日历合法且带明确 Z / offset 的 ISO datetime，校验后再规范成 UTC 判断窗口和编辑顺序。日期-only、无时区、无效日历值隔离，不让 JavaScript Date 自动补午夜或滚动日期。capture 与 status revalidate 使用同一解析约束；合法 offset 并不被误当未知时间。

每组固定最多 6 页 / 100 个收到的项目，响应单页最多 40；实际项目预算取 100 与 SourcePolicy.maxItems 较小者，最多 10 组。下一页只从唯一 `rel="next"` 提取 max_id；验证同 origin / 同 path / 无 userinfo、fragment / 游标不重复，再重建原始 local=true 和 limit 查询。短页不证明完成；空页结束但不声称全窗覆盖；非空缺 Link、越界、重复游标、页数/项目预算耗尽均整组 Gap。不会遇一条旧 created_at 就停止。

每次 capture / revalidate 整轮 30 秒实际 deadline；每 HTTP 使用 SourcePolicy.timeoutMs 与剩余 deadline 的较小者，取消与独立超时 Promise 不依赖底层 DNS / read 是否自行返回。调用者取消在最后一次响应之后也不能得到 unchanged。生产 transport 复用现有证书验证、DNS 地址审查/固定、字节上限和原 hostname/SNI，拒绝重定向；不从正文、Link、头像、附件或错误文字扩出网目标。

429 实例级冷却在同一个 adapter 实例内同时覆盖 capture 和 revalidate；有 Retry-After / X-RateLimit-Reset 时取不早于它们且至少 60 秒的时刻，无有效头也进入 60 秒冷却。本轮不等待重试、不换实例。401/403/422 为 access-unavailable；404/410 仅为本实例不可用，不称作者确认删除；changed / 不合格字段 / 错误响应 / 超时 / 取消均不采用旧稿。只允许固定错误码，外部 exception.message 和任意 social-* 文案不得进入永久原因字段。

单次调用串行请求，Observer 串行复查配置组；本票未提供跨调用的全局任务队列、分布式限流或持久调度。receipt 表最多 100 项，仅保存快照摘要、短期身份与到期时间，不保存原始 API body；过期/权限变化/复查失效使 receipt 不可再用。新 adapter / 进程重启丢失 receipt 后，旧快照为 Gap，不能靠重新读取正文补回 cutoff。

返回的 `DiscourseSample` 是受限不可信来源输入，调用者仅在获准 TTL 内同进程短存并交给 produce，不是通用可永久存储的缓存。正文不会写入 reports SQLite；TTL 到期即禁止模型/出版，但不能承诺安全擦除 JavaScript 堆、调用者已复制的对象或外部导出副本。未实现持久定时采样：capture 可由后续既有作业在 cutoff 前调用，不要求 Owner 每日手抄 dump，也不以这条可调用路径冒充调度已上线。

## 样本投影、阈值与选择

仅保留明确 public、非 sensitive、空 CW、无回复、转发、引用、附件、card、poll 的原发文字。account / IP / 坐标 / 附件 URL / profile / 各类互动数不进入匿名材料。HTML 只解析 p/br 与当前查询 tag 的极小 hashtag anchor/span 结构；验证 class/rel/属性、同 origin 的 /tags/ 路径和可见标签一致后输出 #tag，丢 href/原 HTML。普通链接、mention、图片、事件属性、其他嵌套内容隔离，不追加抓取。正常自有样本已采用官方 formatter 的 a/span 形状，而非仅 p 的不完整替身。

匿名文字再作保守 URL、email、@handle、IP 和电话形状检查；这不是任意正文 PII 检测器，不能保证识别所有姓名、住址或隐含身份。剩余匿名观点仍需要明确模型/存储授权及语义核验。未知/非规范 language 映射 unknown，地域始终 unknown；不从 local、实例域名、查询语言或中文文本推断居民、国籍或人口。

| 冻结规则 | 工程资格含义 |
|---|---|
| Story-linked ≥6 条；native ≥12 条 | 去重与隔离后的实际有效项目数，不是科学抽样代表性阈值。 |
| ≥3 不同原发根帖；两个半窗时间桶均非空 | 只表示返回了多个原发和至少两个时段。作者数未知；根帖不等于不同作者或独立可靠来源，也未读完整线程。 |
| 重复比例 >40% 隔离 | 按收到项目中的重复 ID 或规范化同文计算；不得用复制文本凑量。原发去重后每根最多一条，≥6 已使单根占比低于冻结的 50% 上限；没有作者集中度检测。 |
| 配置/规则/时间起始冻结 | 不允许模型事后换 tag、扩大窗口、补采新正文或调整阈值凑信号。 |

组披露包含平台、固定 tag/local/语言过滤、窗口、实际所见语言、未知地域、收到/去重/隔离/有效数量、时间桶、原发数及失败原因。未取得的数量是 unknown，不是零；空数组和有限遍历同样不证明全平台零讨论。缺口与观察数量分开。

仅一个组的一个 aggregate Evidence 可支持该组的 social-discourse analysis Claim，不能支持 fact / statement / quotation 或混入其他 Edition。每条仍须经过统一 Publication Gate 与 domain-v1，且语义明确 sample-only、非个人画像、原创、安全解释；population / unknown / 错类型均隔离。判断是否真属样本论点仍来自外部 SemanticVerifier，本票不把 JSON 标签当作真实质量验收。

Story-linked 用配置中冻结的普通新闻 Evidence IDs 关联**当前最终入选且唯一**的主 Event Cluster；Candidate.eventClusterId 只表示组身份，不能自报主事件 ID。没有合格主事件或多义关系时不刊观察，也不转成独立新闻。纯历史目标本版不支持，不借历史 ID 补足当前主故事。

Platform-native 可在没有任何普通新闻的当期独立形成样本观察，不创建新闻 Event Cluster。先确定组未失效、恰好一个候选且所有 Claim 可刊，再对合格 native 进行兴趣选择、配额及重点排序；多候选歧义组只产生该组 Gap，不占据其他合格组的 rank / priority。仅已通过所有门的 native analysis 可取得受限 topics/entities 兴趣投影（hash）；regions 固定空、impact 强制 ordinary、无 impactClaimIds / impactBasis / GlobalBaseline。沿开始冻结的 Profile 排序与显式排除；最多 7 个 native、前三个重点，不扩旧 Request 或其他普通 analysis 的选择语义。Story-linked 跟随主故事，不进行独立兴趣选题。

Record 7 读取时独立检查组/观察身份唯一性、门槛计数与两桶、Gap 关联、候选/最终 Gate/证据引用、主 Cluster 链接、native 无主事件、priority 和 Interest selection 重算一致性。原始 API body / `discourseSamples` 快照对象、策略 review/basis、post ID 和原 HTML 不进入 modelRequest；获准的匿名观点原文本会进入 aggregate Evidence，Runner / Verifier 只收到这一匿名聚合文本与必要采样上下文。永久 Record 不保存 samples，最终失效组连复制进 upstreamOriginId 等回执字段的原句也删除。

# Bound interchangeable research agents with a deterministic evidence and publication pipeline

Observer will not treat Codex, Claude, or another coding agent as either its global news source or its publication authority. Reviewed collectors create an Evidence Bundle, a provider-neutral Research Agent produces a structured Report Record, deterministic policy and schema checks authorize publication, and every rendition is derived from one Canonical Brief; we accept the added adapters and pipeline stages to preserve provenance, enforce source rights, recover reliably, and change agent providers without rewriting the product.

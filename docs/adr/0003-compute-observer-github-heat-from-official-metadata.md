# Compute Observer GitHub Heat instead of mirroring GitHub Trending

The GitHub Project Edition will rank eligible public repositories using versioned Observer rules over official API metadata and Observer's own Repository Snapshots, because GitHub exposes neither a supported Trending API nor a public ranking contract. The score emphasizes attention momentum and novelty, applies repeat-coverage decay with one-time material-event overrides, discloses incomplete data, and is never presented as GitHub's official ranking or as a project-quality endorsement.

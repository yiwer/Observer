## What to build

世界要闻、财经、AI 和科技前沿在共同流水线上采用相应证据门，让高风险断言降级为合适归因或待确认，并准确呈现研究成熟度。

## Acceptance criteria

- [ ] 高风险世界要闻至少两个独立可靠来源；高风险财经实行明确且更严格的交叉核验，对不足和矛盾给出隔离/待确认结果。
- [ ] 伤亡、计票、市场背景等动态数字注明统计时间；单方数字归因清楚，不能用另一篇转载形成虚假的交叉确认。
- [ ] 财经成稿保持资讯边界，不输出买卖指令、目标价或收益承诺；无许可的行情与默认排除来源不能为了补齐数字启用。
- [ ] AI/科技的预印本、官方发布、独立验证与同行评审状态分别标记；公司能力声明不自动升级为事实验证。
- [ ] 未核验社交视频和血腥图片不进入报道材料；有证据的冲突、区间与未知保持可读。
- [ ] 提供四类栏目的允许、拒绝和待确认回放样本，从候选输入验证到最终中文正文，并为真实首发源列出需 Owner 审阅的配置记录。

## Scope boundary

共同 Evidence 管线上的主题规则和配置，不为四个 Edition 分别重建采集器或出版系统。

## Decisions and evidence

固定高风险范围、仲裁标准及严重错误示例的输入，供运行复核和评测引用。

验收交接需区分固定数据/替身、真实外部接入和人工检查；结果绑定实际代码及配置版本，缺少证据的类别标为未验证。

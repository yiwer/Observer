规划 ID：V1-17 · 类型：implementation

## What to build

Owner 或未来 Android 设备通过一次性配对取得可撤销访问资格，按日期、Edition 和版本读取私有归档，并获知新增、取代、撤回和缺刊状态。

## Acceptance criteria

- [ ] 历史列表、按日期/Edition/版本读取、当前版本及修订关系查询形成版本化契约；先用固定发布/修订记录验证，不依赖 Android UI。
- [ ] 定义稳定分页/同步游标、排序和重复获取语义，变化记录不会因翻页漏掉新版本；缺刊、降级与延迟字段彼此独立。
- [ ] 一次性配对码限时、原子消费并限制尝试，设备凭证可撤销；Owner 初始化访问通过受控本地管理完成，未认证者不能自行签发配对码。
- [ ] 所有报告、归档和下载默认鉴权；签名下载仅限明确对象、版本和短期限，已撤销设备不能用旧访问路径读取内容。
- [ ] 过期/重复配对、无凭证、伪造凭证、失效签名、越版本访问与撤销后同步均有外部行为测试；合法身份可读取正确版本。
- [ ] 给未来无 GMS 客户端交付可测试的同步契约样例；凭证只保存必要摘要或安全秘密，不写入链接日志和报告。

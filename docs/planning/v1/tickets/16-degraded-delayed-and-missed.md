## What to build

栏目或节点失败时，Owner 仍能区分可读的有效内容、缺口、迟到与缺刊；午前恢复可首发或补齐为新版本，午后不补造正常日报。

## Acceptance criteria

- [ ] 到发布点可用栏目正常发布，失败栏目有原因与 Coverage Gap；延迟与内容降级是独立维度，可以同时存在。
- [ ] 所有 Agent 不可用但采集可信时，发布来源政策允许的标题、来源、时间和链接；正文不出现替身或模型捏造的摘要/分析。
- [ ] 采集也无可信内容时不发空白正常日报；当日 12:00 前恢复完成可发布标注真实时间的 Delayed Brief。
- [ ] 12:00 起不再恢复首发或补齐：从未发布的刊次成为 Missed Brief，已有降级版保留缺口，不伪装成整期缺刊。
- [ ] 午前补齐使用原期合格材料产生 Completion Revision，并保留前后版本关系；普通新进展不混入原刊。
- [ ] 表驱动时钟与故障回放覆盖 08:30、11:59:59、12:00、12:00 后、重启和重复补跑；最多一次提交相同完成修订。
- [ ] 状态模型明确恢复窗口不限制后续 Correction/撤回，给对应票保留受控版本入口。

## What to build

已发布报告及时复制到节点外私有对象存储，并能用数据库、配置及产物的一致性备份在干净环境恢复服务和归档。

## Acceptance criteria

- [ ] 成品发布后及时备份，数据库与配置至少按 RPO 目标生成一致性快照；对象存储私有，清单记录版本、校验值和一致性边界。
- [ ] 秘密采用独立安全恢复流程，不进入普通备份；备份权限与生产写入权限最小化。
- [ ] 从节点外备份恢复报告、索引、版本关系、来源/兴趣配置、任务/投递去重状态，验证重新运行不会重复发送已完成邮件。
- [ ] 来源删除规则覆盖备份保留和恢复：恢复时先应用删除标记及最新策略，再开放读取或触发任务，不复活已禁正文。
- [ ] 定义并记录 RPO ≤24h、RTO ≤4h 的测量起止时点、依赖与失败标准；自动化恢复演练可输出实测数据，不能将目标写作结果。
- [ ] 在隔离环境证明备份损坏、缺少对象、校验失败和恢复中断会被发现；季度演练有可重复入口及持久记录格式。

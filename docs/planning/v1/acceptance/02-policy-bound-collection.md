## Orchestrator 独立检查

预审推动了未审来源测试强化、正常轮询结果与缺口分离、模型/归档独立字段投影、原创摘要不消耗引文额度、实际获取时间跨截稿处理及无效日历日期保留为未知。

在 `689ffaf` 的独立公开接口探针还发现：已批准配置可声明不支持删除义务，却仍采集并进入模型材料。这与来源准入约束不符。最终候选在读取网络或打开缓存前硬拒绝 `approved + deletion.mode=unsupported`，待审 Proposal 仍可见。此项是 root 额外发现，不混入两轴初查计数。

## 限制与后续契约

详细实现和红绿记录见[实现说明](../../../implementation/v1-02.md)，设计见 [ADR-0005](../../../adr/0005-separate-expiring-source-material-from-permanent-reports.md)。

- 网络证据是**真实本地 HTTP socket 加注入 DNS/transport**，不是生产 HTTPS/TLS 或真实出版商资格验证。
- 真实来源政策审阅、真实模型事实支持、生产出版及部署均未验证；生产发布入口仍禁用。
- Bundle v2 独立版本化；旧 Bundle v1 的 13 个测试保留。模型可见材料、引用/归档材料不能重新合为同一权限视图。
- 当前缓存保存最新修订；已取得 Bundle 是独立值，但缓存不能重建所有历史截稿。V1-15 必须实现持久冻结，不得用截稿后最新缓存伪造旧快照。
- TTL 清理在运行和读取时执行；离线停机期间不能删除文件。完整导出物撤回、备份清理和来源专用删除仍属后续票。
- 锁定的 saxes 6.0.0 上游已归档；维护风险已记录，安装审计不等于安全证明。
- 提交尚未 push；Issue 关闭仅记录本地实现验收。

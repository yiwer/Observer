# PDF 中文字体

`NotoSansSC-Regular.otf` 原样取自 Noto CJK **Sans2.004** 发布中的简体中文 SubsetOTF；8,331,336 字节。未改名、未修改字形。字体内保留原版权信息，许可证见同目录 `OFL.txt`。

- [官方固定版本字体](https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf)
- [该发布的 SIL Open Font License 1.1](https://github.com/notofonts/noto-cjk/blob/Sans2.004/LICENSE)

服务只读取这个固定路径，不使用宿主字体目录、动态字体 URL 或报告提供的文件路径。PDFKit 子集嵌入实际使用字形，因此阅读设备无需安装字体。字符缺字时显示明确的 `[U+码位]` 替代和文末提示，原始 Canonical Markdown 同时内嵌在 PDF 中。
